# supermarket_app

A new Flutter project.
A cross-platform mobile application built with **Flutter** featuring dual dashboards for **Customers** and **Administrators**.

## ✨ Features

### 🛒 Customer Dashboard
- Browse available supermarket products.
- Add products to shopping cart and place orders.
- Track order status.

### 🛠️ Admin Dashboard
- **Product Management:** Add, edit, or remove items/stock.
- **Order Management:** Process incoming orders and update order statuses.

## 🛠️ Tech Stack & Status

- **Frontend:** Flutter (Dart)[cite: 6]
- **Backend:** Under development / In Progress (API integration for product & order management)
